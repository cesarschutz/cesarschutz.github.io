# Olá! 👋

Este é o meu cantinho na internet. Sou o **Cesar Schutz**, arquiteto de solução, e criei este espaço com um objetivo simples: **registrar o que eu estudo, construo e aprendo** — e deixar isso acessível para quem mais possa se beneficiar.

## O que você vai encontrar aqui

- **Posts de estudo** — anotações sobre arquitetura de software, desenvolvimento, ferramentas e tudo que estiver explorando no momento
- **Projetos** — coisas que construí ou mantenho, na página [Projetos](/projects)
- **Conteúdos pontuais** — dicas rápidas, comandos úteis, aprendizados do dia a dia

## Como este site foi feito

Este site é estático, gerado com [Astro](https://astro.build) a partir do tema [Yukina](https://github.com/WhitePaper233/yukina), adaptado com um toque pessoal: as cores oficiais do Imortal Tricolor. 🔵⚫⚪

Todo o conteúdo é escrito em Markdown e publicado automaticamente no GitHub Pages a cada push. Sem servidor, sem banco de dados, sem complicação.

> A melhor forma de consolidar um aprendizado é explicá-lo. Por isso este site se chama **Caderno Público**.

Boa leitura!
